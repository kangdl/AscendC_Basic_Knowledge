# 章节导读

## 大模型基础

- 路由：models
- 原稿章节：第一章 大模型基础
- 图标：network
- 编号：00

### 摘要

从单个神经元到训练循环，理解框架和算子如何分工。

### 导读

一次模型训练可以拆成前向计算、损失计算、反向传播和参数更新。先沿着一次训练的路径走一遍，再看矩阵乘法、激活和归约分别出现在哪里。

### 图解：一次训练迭代

| 步骤 | 说明 |
| --- | --- |
| 输入 | 一个小批次 |
| 前向计算 | 得到预测 |
| 损失与梯度 | 衡量误差 |
| 更新参数 | 进入下一轮 |

### 速查表

| 训练步骤 | 做什么 |
| --- | --- |
| 前向传播 | 把输入依次变换成预测值，例如计算 z = Wx + b 后应用激活函数。 |
| 反向传播 | 由链式法则计算损失对各参数的梯度。 |
| 优化器更新 | 用梯度更新参数。最简单的梯度下降是 w ← w − η·∂L/∂w。 |

### 练习

用更新后的权重 1.2 再做一次前向计算，损失是多少？

预测值为 2.4，新损失为 0.18。

### 小节导读

- 1.1 神经元对输入做加权求和、加上偏置，再经过激活函数。全连接层把许多神经元的权重堆成矩阵，整层可以写成一次矩阵乘加。
- 1.2 取标量模型 ŷ = wx，令 x = 2、目标 y = 3、初始 w = 1。以 L = (ŷ − y)² / 2 计算，当前损失为 0.5，梯度为 −2。学习率取 0.1，得到新权重 1.2。
- 1.3 以 PyTorch 为例，张量表达输入和中间结果，自动微分记录运算并计算梯度，后端根据张量所在设备选择相应算子实现。

### 延伸阅读

- [PyTorch 神经网络教程](https://docs.pytorch.org/tutorials/beginner/basics/buildmodel_tutorial.html)

## Transformer 基础

- 路由：transformer
- 原稿章节：第二章 Transformer基础
- 图标：attention
- 编号：01

### 摘要

看懂 Q、K、V 与因果掩码，再追踪多头和 KV Cache。

### 导读

Attention 为每个查询计算一组权重，再对值向量做加权求和。从单头的四个 token 出发，追踪维度、掩码和中间张量。

### 速查表

| 张量 | 含义 |
| --- | --- |
| Q · N × dₖ | 每一行是一个位置的查询向量。 |
| K · N × dₖ | 每一行是一个位置的键向量，与查询做点积。 |
| V · N × dᵥ | 每一行是一个位置的值向量，按注意力权重汇总。 |
| O · N × dᵥ | 每个查询位置最终得到的输出向量。 |

### 练习

当第 3 个 token 是查询时，哪些 token 可以参与计算？

第 1、2、3 个可以参与，第 4 个被因果掩码屏蔽。

### 小节导读

- 2.2 分数矩阵 S = QKᵀ / √dₖ。将被遮挡的位置设为 −∞，对每一行做 Softmax 得到 P，再计算 O = PV。章首页的因果注意力图解标出了掩码允许的位置。
- 2.3 位置沿行维度排列，特征沿列维度排列。多头注意力并行计算多个头，随后拼接各头的输出并做一次输出投影。
- 2.5 FlashAttention 通过分块和在线 Softmax 减少显存读写。
- 2.6 自回归解码时，KV Cache 保留已经处理过的位置的 K、V，避免重复计算。
- 2.7 反向传播从输出梯度开始，沿 O = PV、Softmax、缩放点积依次回传。若 Q、K、V 都来自 X，对 X 的梯度来自三条投影路径的贡献之和。
- 2.8 GQA 让一组查询头共享一组 K、V。
- 2.10 MLA 通过低秩表示压缩缓存所需的信息。比较方案时，可以从每个 token 需要保存多少元素算起。

### 延伸阅读

- [FlashAttention](https://arxiv.org/abs/2205.14135)
- [GQA](https://arxiv.org/abs/2305.13245)
- [DeepSeek-V2（MLA）](https://arxiv.org/abs/2405.04434)

## AscendC 算子

- 路由：ascendc
- 原稿章节：第四章 AscendC算子
- 图标：flow
- 编号：03

### 摘要

从向量加法认识搬入、计算、搬出三段流水。

### 导读

以向量加法为例，每次处理一块输入。把输入从全局内存搬到片上，执行逐元素相加，再将结果写回全局内存。

### 图解：向量算子的三段流水

| 步骤 | 说明 |
| --- | --- |
| CopyIn | 输入搬到片上 |
| Compute | 在片上计算 |

### 速查表

| 对象 | 在向量流水里的作用 |
| --- | --- |
| GlobalTensor / LocalTensor | 分别描述全局内存和片上内存中的张量。 |
| TQue | 在核内流水任务之间传递张量并实现同步。 |
| TPipe | 为流水任务管理队列缓冲区等资源。 |

### 练习

CopyOut 阶段需要等哪一步完成？

等待 Compute 将输出张量计算完并放入输出队列。

## 数据类型与量化

- 路由：quantization
- 原稿章节：第六章 数据类型与量化
- 图标：levels
- 编号：05

### 摘要

用一组数字体验量化、反量化与舍入误差。

### 导读

量化用有限的低精度数值表示连续或高精度数据。最简单的对称均匀量化可以写成 q = clamp(round(x / s))，反量化时计算 x̂ = s·q。

### 图解：对称量化示例（scale = 0.5）

| 步骤 | 说明 |
| --- | --- |
| 原值 | x = 1.2 |
| 量化整数 | q = round(2.4) = 2 |
| 反量化 | x̂ = 1.0 |

### 速查表

| 数据类型示例 | 表示特点 |
| --- | --- |
| FP32 | 32 位浮点，包含符号位、指数和尾数。 |
| FP16 与 BF16 | 同为 16 位浮点。BF16 的指数范围更大，FP16 的尾数位更多。 |
| INT8 | 8 位整数。用来表示量化张量时，通常需要同时记录缩放因子。 |

### 练习

缩放因子保持 0.5，把 0.76 量化后再还原，结果是什么？

round(0.76 / 0.5) = 2，还原结果为 1.0（假定未超出整数表示范围）。

## Tiling 优化

- 路由：tiling
- 原稿章节：第七章 Tiling优化
- 图标：blocks
- 编号：06

### 摘要

把数据切成可执行的块，理解尾块、片上容量与并行度。

### 导读

Tiling 将大张量划分为更小的计算块。选择块大小时，同时考虑片上空间、访存对齐、尾块处理与并行程度。

### 图解：长度 18、块大小 8 的示例

| 步骤 | 说明 |
| --- | --- |
| 块 0 | 索引 0–7 |
| 块 1 | 索引 8–15 |
| 尾块 | 索引 16–17 |

### 速查表

| 调优维度 | 验证方式 |
| --- | --- |
| 正确性 | 检查非整块输入，确认尾部只处理有效元素。 |
| 片上空间 | 核算同一时刻仍然存活的输入、输出和临时缓冲。 |
| 吞吐 | 在目标设备上比较多组块大小，查看延迟或带宽。 |

### 练习

只改变块大小为 6，长度 18 的向量会出现尾块吗？

不会。每块 6 个元素，正好需要 3 块。
